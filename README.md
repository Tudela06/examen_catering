# Examen UD1 - Presupuesto de Catering
Aplicacion PP para gestionar un presupuesto de catering usando sesiones.

## Archivos
- `datos.php`: array de servicios de ejemplo.
- `imprimir.php`: muestra la tabla estatica y estadisticas.
- `gestionar.php`: aplicacion dinamica con sesiones, formulario, eliminacion y modificacion de unidades.

## Uso
1. Colocar un servidor PHP.
2. Abrir `imprimir.php`para ver el ejemplo estatico.
3. Abrir `gestionar.php`para la version interactiva.
